Last updated {{ privacy_updated }}

The short version. MeshRadio has no accounts, no ads and no analytics or tracking scripts. It doesn't sell or share anything about you, and it only remembers what it needs to keep your music playing.

Cookies and browser storage

    {% if embed_mode %}
  • mr_sid keeps your own queue and player across visits. It holds a random ID and nothing else, lasts a year, and can't be read by scripts. Your queue is kept on the server under that ID and deleted a week after it last changed.
    • {% endif %}
  • skin remembers which skin you picked, for a year.
  • Your equalizer settings and a couple of display choices are saved in your browser's local storage. They never leave your device.
  • The site's admin gets a sign-in cookie. Visitors never do.

All of these are first-party and needed for the site to work, so there's no consent banner. Clearing this site's data in your browser removes them.

YouTube

{% if embed_mode %}

Songs play through YouTube's embedded player, and song thumbnails load from YouTube's image servers. That means YouTube sees your IP address and can set its own cookies while you listen, under Google's privacy policy. MeshRadio doesn't control or receive any of that data.

{% else %}

This radio plays audio it has saved itself, but song thumbnails still load from YouTube's image servers, so YouTube sees your IP address when your browser fetches them, under Google's privacy policy.

{% endif %}

Your IP address

MeshRadio uses your address for a short time, in memory only, to stop any one visitor from flooding the site with requests. It doesn't write visitor addresses to disk or keep access logs. {% if embed_mode %}The site is hosted on Render, which may keep its own standard request logs.{% endif %} Attempts to sign in to the admin page, and changes made there, are logged with the address they came from.

Songs and names

The songs, themes and names you see here come from the Austin MeshCore #music channel, which is public to anyone on the mesh. Each song is shown with the name its sharer used on the channel. If you shared a song and want your name or the song taken down, open an issue on GitHub and it will be removed.

Changes and questions

Changes to this page show up here with a new date, and every past version is in the project's history on GitHub. Questions go to the same issue tracker.
